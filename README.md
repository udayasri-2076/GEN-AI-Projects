# 🤖 GenAI Projects

A collection of practical Generative AI applications built using Python, LLMs, and modern AI tools.

## 🚀 Projects

### 1. DSA Automation
Automates the generation of DSA study materials from coding solutions, with a review-and-approval workflow.

**Tech Stack:** Python, FastAPI, PostgreSQL, SQLAlchemy, GitHub Webhooks, Gemini API, Telegram

### 2. Chat with PDF
A PDF question-answering application that uses Retrieval-Augmented Generation (RAG) to answer questions based on uploaded documents.

**Tech Stack:** Python, Streamlit, LangChain, FAISS, Gemini API, Groq

## 🎯 Purpose

Building practical AI applications while exploring LLM integration, backend development, and document retrieval.
